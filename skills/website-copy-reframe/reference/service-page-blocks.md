# Service / offer-page blocks

Mode `service-page`. Different job from the homepage: ONE service deep, bottom-funnel, SEO.
The homepage picks one champion across the company; a service page goes deep on one offer for
the buyer already looking for that service. Reuse the canvas, but narrow it to this offer.

Cite the canvas cell per block (rationale line). Obey the client's voice rules.

## Block order

### 1. Hero
```
[Service name — as the market searches for it]
H1: <the champion outcome this service delivers> + <one proof metric>
Sub: <one line: how it works / what makes it real>
CTA: <the demo/sample next step>
Trust: <2–3 numbers relevant to THIS service>
```
*Rationale:* H1 = capability + benefit + a proof-bank number. Search-legible service name = SEO H1.

### 2. What it is / what gets done (fundamental #3)
Concrete deliverables, named. Formats, standards, tolerances. Not "solutions" — the actual output.
> e.g. "Classified LAS/LAZ, ground/off-ground, powerline extraction, DEM/DTM/DSM, contour generation."

### 3. Problems it fixes (from limitations → problems, scoped to this service)
3–4 bullets: the specific pain this one service removes for the champion. Pulled from the canvas
left half, filtered to this offer.

### 4. Benefits (numeric where possible)
The outcomes of using it — tied to the champion's job. Lead with a number from the proof bank.

### 5. Proof (the offer's matched cases + testimonial)
The 1–2 cases tagged to THIS offer in the proof bank, result-first, + one attributed testimonial.
Never borrow another offer's case here.

### 6. How it works / engagement (fundamentals #2, #4)
The steps and the commercial model for this service: turnaround, per-deliverable vs dedicated,
start time, security/NDA. The "when would I use it" answer.

### 7. FAQ / objections
Pre-empt the buying blockers for this offer (from the ICP's blockers): IP/NDA, QC/standards,
data security/sovereignty, "price?", "can you handle our volume/format?". Answer each in 1–2 lines.

### 8. SEO map
- **Target keyword cluster** — 1 primary + 2–3 secondary (match the ICP's search language).
- **Title tag** (≤60 chars) + **meta description** (≤155, includes the metric + CTA).
- **H1/H2 outline** — H1 = service + outcome; H2s = deliverables · problems · proof · process · FAQ.
- **Internal links** — to homepage, sibling offer pages, matched industry page, matched case.

### 9. CTA
Same next step as hero — the demo/sample. Low friction. No "free pilot" language.

## Multi-offer note
When a client has N offers, run this mode once per offer. Keep the shared shell (voice, trust bar,
engagement models) identical; swap the offer-specific canvas cells + matched proof so each page is
distinct and each ranks for its own cluster. Colour-code each offer per the design system (one
accent per offer) if there is one.
