## Rules
- **Source or cut.** No unsourced benchmarks. "All figures from delivered client projects" only if true.
- **One case per claim per page** — don't reuse the same case across every offer; match it.
- **Heritage anchors stay anchors** — a parent/heritage brand is domain-credibility only, never a competing service.
- Keep the bank in the copy-deck so the client can extend it as new proof lands.
