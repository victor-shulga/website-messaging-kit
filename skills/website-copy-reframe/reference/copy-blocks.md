# Copy-block templates + worked examples

Templates for Step 6. Each block cites the canvas cell it draws from. Keep copy concrete,
tool-agnostic in the situation, vertical in positioning. Humanize via `anticopywriting-ai`
before shipping (no "не X, а Y", no канцелярит, no AI-slop).

## Canvas table (fill this first, one primary use case)

| Left half (current path) | | | Right half (your service) | | |
|---|---|---|---|---|---|
| **Audience** | company type × person × situation | | **Capabilities** | what they do with the service | |
| **Champion** | who feels the pain, pushes the deal | | **Features** | tech that enables the capability | |
| **Situation / Activities** | functional, tool-agnostic | | **Benefits** | result of the capability | |
| **Current Way** | how they handle it today | | | | |
| **Limitations** | neutral facts of the current way | | | | |
| **Problems** | what the limitations cost the champion | | | | |

Rule of the links: Capabilities **improve** Limitations · Benefits **solve** Problems.

---

## Hero (top-row message + key capabilities + category + trust)

```
[Service category the market already searches for]
H1: <capability the champion gets> for <specific audience>
Sub: <how it works in one line — the feature that makes the capability real>
     <the benefit that resolves their top problem>
CTA: <next step — book a call / get an estimate>
Trust: <logos · # projects · geo · certification · years>
```
*Rationale:* H1 = top-row + key Capability · Sub = Feature + Benefit · Trust = social proof.

**Worked example**
- Category: *Fractional GTM for B2B service companies*
- H1: *Generate pipeline and close more deals*
- Sub: *With detailed SOPs, frameworks, templates, and experience to hit targets — to 2x
  new revenue with leads that fit your ICP.*

## Problem Section (current way → limitations → problems)

```
Header: <name the situation the champion is actively working on>
Lead: <empathy line — "if you're trying to <situation>, you've probably tried <current way>">
3 bullets, each = one Limitation → its Problem:
  • <current-way limitation> — which means <problem it causes the champion>
Close: <one line that repels bad-fit and confirms good-fit>
```
*Rationale:* pulled straight from Current Way / Limitations / Problems cells. Purpose:
empathy + qualification (attract fit, repel non-fit).

---

## Solution (3 arguments → next step)

```
Header: <the progress the champion wants to make>
3 argument cards, each = Capability + Feature + Benefit:
  1. <capability> — <feature that enables it> → <benefit that removes a problem>
  2. …
  3. …
CTA: <same next step as hero — form or calendar>
```
*Rationale:* drawn from canvas rows 2–4 (Capabilities / Features / Benefits). These are
the 3 reasons to act now.

## Optional lower-half sections (pick per client; each routes to another page)

- **Services** — grid of services → each links to its service page.
- **Industries** — verticals served → industry pages (proof of domain fit).
- **Testimonials** — quotes tied to the problem the champion has.
- **Why work with us** — differentiators (team, how-we-work, awards, guarantees).
- **Persona-based segmentation** — "here's how <persona A> uses the service / <persona B>…".
- **Company-based segmentation** — "here's how <industry A> uses it / <industry B>…".
- **ROI** — numeric outcomes (%, $, time saved) with source.
- **Calendar / Form** — final CTA, low-friction.

## Reframe heuristics (turning scraped copy into the canvas)

- Scraped headline is usually a **founder-view capability dump** → demote to raw material,
  re-derive the champion's situation underneath it.
- "We offer X, Y, Z services" → ask *what activity is the champion doing that needs X* →
  that activity is the Situation row.
- Adjective-heavy trust claims ("innovative, reliable, cutting-edge") → cut; replace with
  a Feature (concrete mechanism) or a numeric Benefit.
- If the current copy speaks to the buyer/exec, rewrite one level down to the champion.
- Kill horizontal "we help all kinds of businesses" → pick the one vertical (Step 2).
